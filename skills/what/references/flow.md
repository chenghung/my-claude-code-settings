# 方框加箭頭流程圖

用來呈現流程、資料流與元件間的互動。

## 畫法

- 每個參與者或步驟一個方框，用 `┌─┐│└┘` 畫。中文字佔兩格寬，補空白對齊右框線時要算進去。
- 方框之間用 `──▶` 連接；往下用 `│` 加 `▼`。
- 箭頭上方或旁邊寫傳遞的東西，例如 `── prompt ──▶`。
- 分支用 `├──▶` 拉出，並在箭頭旁寫條件。
- 一張圖最多六個方框；更多就拆圖。

## 範例

```text
┌────────┐  /what   ┌────────┐  讀取   ┌──────────────┐
│ 對話者 │ ───────▶ │ agent  │ ──────▶ │ 對應的       │
└────────┘          └───┬────┘         │ reference    │
                        │              └──────────────┘
                        │ 輸出
                        ▼
                  ┌────────────┐
                  │ 結論＋圖   │
                  └────────────┘
```

## 文字說明

照箭頭順序說明：從起點的方框開始，每段箭頭講一句「誰把什麼交給誰」，走到終點為止。
