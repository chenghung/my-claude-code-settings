# 分層堆疊圖

用來呈現誰在誰上面、誰依賴誰。上層依賴下層。

## 畫法

- 每層一個方框，用 `┌─┐│└┘` 畫，所有方框同寬。
- 方框內左邊寫層名，右邊寫該層負責的事。中文字佔兩格寬，補空白對齊右框線時要算進去。
- 層與層之間直接相疊，用 `├─┤` 當分隔線。
- 要強調的層，在方框右側加 `◀ 說明`。

## 範例

```text
┌──────────────────────────────────┐
│ skill     what 的流程與規則      │ ◀ 本次修改
├──────────────────────────────────┤
│ harness   Claude Code / opencode │
├──────────────────────────────────┤
│ 模型      讀指示、產生回覆       │
└──────────────────────────────────┘
```

## 文字說明

由上往下或由下往上擇一，並在說明開頭寫明方向，例如「由上往下：skill 交給 harness，harness 交給模型」。之後整段都照這個方向講。
