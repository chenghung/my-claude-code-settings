# 巢狀清單

用來呈現概念大綱與分類。直接寫 markdown 清單，不放程式碼區塊。

## 畫法

- 第一層是分類，第二層是分類下的成員，第三層才放細節。
- 每項開頭是名詞或短語，冒號後接一句說明。
- 同一層的項目用同一種切法分類，例如全按「誰負責」或全按「何時發生」。

## 範例

- **觸發方式**
  - 手動：使用者輸入 `/what` 才執行
  - 自動：不提供
- **輸出**
  - 結論：一句話
  - 全局前提：圖撐不住才補
  - 圖：1 到 3 張，背景寫在說明裡

## 文字說明

先講分類的切法，例如「這裡按輸出順序分」。再挑對話者最需要的那一類展開，其餘一句帶過。
