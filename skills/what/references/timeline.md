# 步驟線

用來呈現走過哪些路、現在在哪。

## 畫法

- 一行一個步驟，由上往下按時間排。
- 步驟前用符號標狀態：`✓` 已完成、`▶` 現在、`○` 還沒做、`✗` 放棄的路。
- 放棄的路寫一句放棄的原因。
- 「現在」那一行在右側加 `◀ 現在`。

## 範例

```text
✓ 1. 確認需求：手動觸發、1 到 3 張圖
✗ 2. 用 Mermaid 畫終端機圖 — 終端機無法渲染
✓ 3. 改用 Unicode 框線字元
▶ 4. 撰寫 reference 檔                ◀ 現在
○ 5. 試跑並檢查
```

## 文字說明

先講「現在」在哪一步、這一步在做什麼。再回頭用一兩句講怎麼走到這裡，最後講下一步。
