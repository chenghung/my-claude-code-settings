# ASCII 樹

用來呈現階層與全貌。

## 畫法

- 根放第一行，子節點用 `├──` 與 `└──` 接出，往下一層用 `│   ` 縮排。
- 每個節點後面可加 `# 說明`，一個節點只寫一句。
- 只留跟討論點有關的節點，其餘收成一個 `└── …`。
- 深度控制在三層內；更深就拆成第二張圖。

## 範例

```text
設定 repo
├── rules/            # 每次對話都載入的規則
│   └── diagram-output.md
├── skills/           # 依需求才載入的流程
│   ├── what/         # 本次新增
│   └── …
└── install.sh        # 把上面兩者裝到各 agent
```

## 文字說明

由主幹往分支說明：先講根是什麼，再講第一層各分支的分工，最後才點出要使用者注意的那個葉節點。
